# THE RE:FINE 정식 런칭 홈페이지

청주 가경동 피부관리 **더리파인 에스테틱** 정식 런칭용 정적 사이트입니다.

## 주요 반영 사항
- 실제 더리파인 매장 사진과 제공 로고로 전면 교체
- 핵심 SEO 문구를 `청주 가경동 피부관리`로 통일
- 얼굴경락, 윤곽관리, 스킨케어, 데콜테, 리프팅, 모공, 아쿠아필, 웨딩/신부관리 키워드를 페이지별로 자연스럽게 배치
- 업체 소개의 퍼스널 페이스 큐레이션, 도합 22년 경력, 1:1 분석, 시퀀스 설계, 프라이빗 케어 반영
- 주소/주차/연결통로 안내 반영
- 모바일 고정 전화/네이버 예약 CTA 유지
- Open Graph, JSON-LD(BeautySalon), sitemap, RSS 업데이트

## 배포
Cloudflare Pages 기준 Framework preset은 None으로 두고 이 폴더의 내용을 저장소 최상단에 올리면 됩니다. Build command를 비우고 루트 정적 배포를 권장합니다. 기존 설정이 `node prepare-seo.mjs` / output `public`이라면 호환용 스크립트가 동일 파일을 `public/`로 복사하므로 그대로도 배포할 수 있습니다.
현재 canonical 대표 주소는 `https://skin-cheongju.pages.dev` 입니다. 커스텀 도메인으로 바꾸면 모든 HTML의 canonical/OG/JSON-LD, sitemap.xml, rss.xml, robots.txt 대표 주소도 함께 교체하세요.
